(`BLOTATO_ACCOUNTS`, "verified live 2026-10-22"). The pre-flight's account check asked only

🔑 **It matters now, not later:** reconnecting Meta is the top blocker on the board and

* a targeted id that is not live, while that platform HAS live accounts → **FAIL** (blocks);

  the new check is **additive, not a replacement**.

original platform-only implementation and proves it stayed silent on exactly the stale-id
case the fix catches. Wired into `ops/run-tests.sh`.
