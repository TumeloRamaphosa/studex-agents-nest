## 🔴 The fourth false green — and it was in the leak detector

`ops/check-scanner-log-exposure.py` exists for exactly one purpose: to catch a
credential being **printed into the gateway log**. That is the recurring leak —
stdout of tool output is captured into the log.

At **08:46 UTC** the surface audit measured the log and found **18 LIVE and
UNKNOWN credential literals** in it. At **08:47 UTC** this checker ran and said:

```
distinct candidates the scanner printed into the gateway log: 0
No live .env credential was printed into the gateway log.
```

Both were true at the same moment, about the same file.

**Why.** It found candidates by matching **one tool's** output line format:

```
<rel>:<line>  '<matched value>'
```

That is the shape-scanner's format. The literals in the log had been written by
**other** tools, in **other** formats. The checker could not see them — so it
reported a leak that did not happen over a leak that did.

🔑 **A detector that cannot see a failure mode must not be allowed to report a
clean result.** Its presence is worse than its absence: it suppresses the
search it was standing in for. This is the **fourth** instance of the same
shape in one toolchain — the previous three were the AgentMail probe dialect,
the redactor's UNKNOWN-only skip, and the redactor's LIVE-only verify.

### Fixed — `63a99af8`

- The checker now also asks the **value question**: does the log hold the full
  value of any credential in `.env`, **whatever tool printed it and in whatever
  format**. That is the check that would have caught 08:46.
- Both tools now share **one definition** of "alive" and **one definition** of
  "exposure", loaded **by path** from `tmp-credential-surface-audit.py`. Its
  hyphenated filename means it was never importable by name — which is
  *precisely why* the two were free to drift apart and disagree about the same
  file. `DEAD` (provider rejects it) is not exposure; `LIVE` and `UNKNOWN` both are.
- The verdict now rides on the **exit code**. A leak that is found but does not
  fail the command gets forgotten.

verdict that is not carried by an exit code is a report, not a check.
