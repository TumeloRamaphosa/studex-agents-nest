### The lesson, now four instances deep
Every one of these was the same mistake wearing a different hat: **a checker
that only checks what it was told to check reports CLEAN and is wrong.**
- prefix-blind regex → missed Blotato
- hardcoded file list → missed the quarantine
- `live` vs `unknown` mismatch → missed unprobeable keys
- prefix-only probing → missed GoDaddy

The general form: **a green verdict is only as good as the coverage statement
that accompanies it.** So the audit now prints how many files it read. A
verdict that cannot say what it did not look at is a verdict that should not
be trusted. 🔑 **Ask "what did this NOT check?" before believing "CLEAN".**
