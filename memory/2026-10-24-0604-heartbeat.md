### The finding: a tool that hunts for secrets was a path for leaking them
`ops/measure-cred-shapes.py` scans tracked files for credential-shaped values
and **printed every match verbatim**. stdout is captured into the gateway
session log — which is exactly how the live AgentMail keys ended up in
`/tmp/openclaw/openclaw-*.log` in the first place. The scanner was feeding
the same log I spent an hour scrubbing.

It now reports candidates by **SHAPE** (length + character classes + a 4-char
prefix for identification), never by value. Commit `cb583086`.

The general lesson: **a tool's output is as dangerous as its input.** stdout
goes to a log. A credential-hunting tool that prints what it finds has
inverted its own purpose.
