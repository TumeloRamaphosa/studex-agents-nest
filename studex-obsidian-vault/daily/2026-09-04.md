### ✅ Primary Deliverable: Blotato Cross-Post Automation CLI
**File**: `/workspace/studex-social-pipeline/blotato-automation.js`

A production-ready Node.js CLI that orchestrates the Naledi VM content pipeline → Blotato → all connected social platforms.

**Features:**
- `--connect-accounts` — Checks which FB/IG/LinkedIn accounts are connected to Blotato; guides reconnection if any are missing
- `--post --latest` — Picks up the most recently approved content from Naledi VM output dir, posts to Facebook via Blotato API, logs the result
- `--status` — Shows pipeline health: last post time, total posts, connected accounts, queued content
- `--dry-run` — Previews caption and content without posting

**State tracking:**
- `state.json` — tracks connected account IDs + posted filenames (prevents double-posting)
- `post-log.json` — last 100 posts with timestamps, post IDs, and status

**Pipeline chain:**
```
Naledi VM Content Pipeline
  → /workspace/studex-naledi-content/output/approved/
  → blotato-automation.js --post --latest
  → Blotato API
  → Facebook Page + Instagram + LinkedIn
  → post-log.json (audit trail)
```
