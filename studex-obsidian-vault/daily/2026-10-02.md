## 🔨 Build Hour Output — Friday Oct 2

**Built:** [[Studex Order Pipeline]] — webhook-driven automation connecting Shopify → Discord + AgentMail

### Files Created
- `/workspace/studex-order-pipeline/server.js` — Express webhook server (Node.js)
- `/workspace/studex-order-pipeline/package.json` — dependencies
- `/workspace/studex-order-pipeline/.env.example` — environment template
- `/workspace/studex-order-pipeline/ecosystem.config.js` — PM2 process manager config
- `/workspace/studex-order-pipeline/deploy-orgo.sh` — one-command deploy script
- `/workspace/n8n-workflows/studex-order-pipeline.json` — n8n workflow (no-code alternative)

### What It Does
```
Shopify order.created webhook
  → POST /webhook/shopify/orders/create
  → HMAC signature verification
  → Promise.all([
      postDiscord(embed + ping),   // 🛒 ops channel
      sendAgentmail(branded HTML), // customer acknowledgement
    ])
  → 200 OK to Shopify (< 5s SLA)
```

### Activation Steps
1. Set credentials in `.env` (Shopify webhook secret, Discord bot token, AgentMail API key)
2. Register Shopify webhook: `shopify webhook create --topic=orders/create --address=https://YOUR_VM:3000/webhook/shopify/orders/create`
3. Deploy to Orgo VM: `scp` files → `npm install` → `pm2 start ecosystem.config.js`
