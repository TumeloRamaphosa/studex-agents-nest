### 1. 🔴 CRITICAL FIX — the CIIE email source-of-truth gap — SHIPPED ✅

**The bug Build Hour found at 19:14 UTC and was killed before fixing.**

`ciie-nurture` is a TypeScript project: **`src/emails.ts` is the source, `npm run build` compiles it to
`dist/emails.js`, and `dist/emails.js` is what the sender actually uses.** The two had diverged:

| Constant | `src/emails.ts` (source) | `dist/emails.js` (what sends) |
|---|---|---|
| `COFFEE_URL` | `anvkfflansa9` ❌ **retired** | `eukr32nxiptw` ✅ live |
| `CHINA_URL` | `hketvigqcs2f` ❌ **retired** | `lqzo3q09yntr` ✅ live |
| `CAVIAR_URL` | `fa4xt0vnu67u` ❌ **retired** | `ess0ocgcd9f0` ✅ live |
| `MEAT_URL` | `nzj87hus15vc` ❌ **retired** | `nudsduvyrc12` ✅ live |

**Why this was a live landmine:** the 21 Oct fix corrected the copy in `dist/` only. The moment anyone
ran `npm run build` — a completely routine action, and the documented build step for this project —
`tsc` would have **silently rolled back all four URLs to retired deployments**, and the next email to
a real buyer would have carried a dead coffee page, a dead China page, a dead caviar page and a dead
retail page. Every one of those URLs **still serves the old copy**, so the emails would have looked
plausible while pointing at superseded content.

**The fix:** patched `src/emails.ts` to the canonical live URLs, then rebuilt and **proved the
rebuild is safe** by diffing the output against the live dist:

```
diff /tmp/emails.dist.bak dist/emails.js  →  IDENTICAL
```

The rebuilt `dist/emails.js` is **byte-identical** to the live one. That is the proof that
`src/emails.ts` was the *only* divergence — no other source/dist drift was hiding behind it.
**The build path is now safe to run.**

**Verification:**
- `npm run build` → exit 0, no TypeScript errors
- `grep space.mcode.io dist/emails.js` → the four canonical URLs, unchanged
