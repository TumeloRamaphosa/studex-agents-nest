## What It Does

```
Shopify order.created webhook
  → POST /webhook/shopify/orders/create
  → server.js verifies HMAC signature
  → Promise.all([
      postDiscord(order),    // Embed + notification to 🛒 ops channel
      sendAgentmail(order),  // Branded HTML acknowledgement to customer
    ])
  → 200 OK back to Shopify (< 5s SLA)
```

**Discord notification includes:**
- Order number, customer name + email
- Line items with quantities and ZAR prices
- Total, shipping cost, payment status
- Studex green embed color

**AgentMail acknowledgement includes:**
- Customer name personalisation
- Order number + summary
- "We'll WhatsApp you tracking when it dispatches" message
- Studex branded HTML template

## How to Activate (3 Steps)

### Step 1 — Get credentials

In `.env`, set:
```
SHOPIFY_WEBHOOK_SECRET=   # Shopify Admin → Settings → Notifications → Webhooks
DISCORD_BOT_TOKEN=        # Discord Developer Portal → your app → Bot → Token
DISCORD_CHANNEL_ID=1538825048465481728  # 🛒-meat-store--coffee-ops (confirmed)
AGENTMAIL_API_KEY=       # app.agentmail.to → Settings → API Keys
AGENTMAIL_INBOX=studex-2571@agentmail.to
```

### Step 2 — Register Shopify webhook

Shopify Admin → Settings → Notifications → Webhooks → Create:
- Event: **Orders create**
- URL: `https://YOUR_VM_PUBLIC_IP:3000/webhook/shopify/orders/create`
- Format: JSON

Or via Shopify CLI:
```bash
shopify webhook create \
  --topic=orders/create \
  --address=https://YOUR_VM_IP:3000/webhook/shopify/orders/create
```

### Step 3 — Deploy to Orgo VM

```bash
cd /workspace/studex-order-pipeline
scp -r . root@67.213.119.157:/root/robusca/studex-order-pipeline
# Then SSH in and run:
```
