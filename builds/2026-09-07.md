## What Was Built

### 1. n8n Deployment Script (`/workspace/builds/deploy-n8n.sh`)
A fully automated bash script that:
- Detects Alibaba Cloud Linux on the VM
- Installs Docker (yum install docker)
- Starts the Docker daemon manually (no systemd)
- Pulls `n8nio/n8n:latest` image
- Creates `/opt/n8n/data` and `/opt/n8n/workflows` directories
- Uploads the existing `studex-content-pipeline.json` workflow to the VM
- Creates `/opt/n8n/.env` with credentials for Discord, Blotato, Higgsfield
- Starts the `n8n-studex` Docker container on port 5678
- Provides manual workflow import instructions

### 2. SA Cafe Outreach Email Template (`/workspace/builds/outreach-sa-cafes-email.txt`)
Personalised B2B cold email template targeting Cape Town boutique cafes:
- Customisable with cafe name and contact name
- Rwanda A1/A2 coffee pitch — direct trade, Rainforest Alliance certified
- Sample sack offer with first-order credit
- Call-to-action: 15-min call + sample sack
