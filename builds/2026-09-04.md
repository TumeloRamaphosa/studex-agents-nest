## 🎯 What I Built

### `studex-social-pipeline/blotato-automation.js`

A production-ready Node.js CLI that orchestrates the Naledi VM content pipeline → Blotato → all connected social platforms.

**Location:** `/workspace/studex-social-pipeline/blotato-automation.js`

**What it does:**
1. `--connect-accounts` — Checks which FB/IG/LinkedIn accounts are connected to Blotato; guides reconnection if any are missing
2. `--post --latest` — Picks up the most recently approved content from Naledi VM output dir, posts to Facebook via Blotato API, logs the result
3. `--status` — Shows pipeline health: last post time, total posts, connected accounts, queued content
4. `--dry-run` — Previews caption and content without posting

**State files:**
- `state.json` — tracks connected account IDs + posted filenames (prevents double-posting)
- `post-log.json` — last 100 posts with timestamps, post IDs, and status
