## What It Does

A full operations dashboard for the Studex Auto Meat cold-chain business. It provides:

### Pages
1. **Dashboard** — KPI overview (active orders, delivered today, revenue, cold-chain compliance %) + active delivery cards grid
2. **Orders** — Full order table with status filter tabs, cold-chain badges, and click-to-expand order detail panel
3. **Analytics** — 7-day revenue/orders area chart + delivery performance metrics table

### Order Detail Panel (slide-in)
- Order status + cold-chain badge
- Mini-KPIs: product, value, weight
- **Temperature chart** — Area chart of temp readings over time (safe zone 0–4°C)
- **Tracking timeline** — Full event history with colored status dots
- Delivery ETA / actual delivery time

### Data
6 realistic mock orders with full tracking histories and temp readings:
- JHB, CPT, DBN locations
- Mix of statuses: confirmed → processing → dispatched → in_transit → out_for_delivery → delivered
- Real temperature readings per order

### Design
- Deep charcoal (#080808) background — premium butchery aesthetic
- Red accent (#dc2626) — consistent with meat brand
- JetBrains Mono for data values
- Temperature chart glow on the red accent
- Live pulse dot in header
