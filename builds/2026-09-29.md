## What Was Built

**Studex Lead Router** — a GPT-powered B2B lead classification and routing engine.

A Node.js/Express backend service that:
1. Receives inbound leads via webhook (AgentMail + website forms)
2. Classifies each lead with GPT-4o-mini across 4 dimensions
3. Sends a rich Discord embed notification with full lead details
4. Routes the email to the correct AgentMail inbox (Coffee / Caviar / Biltong / General)

## Classification Logic

GPT-4o-mini classifies each lead into:

| Field | Values |
|-------|--------|
| category | HOTEL, RESTAURANT, RETAIL, OCS, OTHER |
| urgency | HIGH, MEDIUM, LOW |
| product_interest | Coffee, Caviar, Biltong, Cold Brew, B2B Partnership |
| reply_tone | Formal, Relaxed, Urgent |

### Inbox Routing

| Category / Product | Routed Inbox |
|--------------------|-------------|
| HOTEL, RESTAURANT, Coffee, Cold Brew | Coffee inbox |
| Caviar | Caviar inbox |
| Biltong | Biltong inbox |
| Other | General inbox |

## AgentMail Integration Setup

In AgentMail dashboard:
1. Create a new workflow
2. Trigger: **"When email received"**
3. Action: **"Send webhook"**
   - URL: `http://<server>:3001/webhook/agentmail`
   - Method: POST
   - Body mapping: `from`, `subject`, `body`, `sender_name`

---

## Discord Integration

1. In Discord: Server Settings → Integrations → Webhooks → New Webhook
2. Name it "Studex Lead Bot"
3. Copy webhook URL into `.env` as `DISCORD_WEBHOOK_URL`
4. All leads will post as rich embeds with category color, urgency emoji, and full details
