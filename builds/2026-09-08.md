## What It Does

### Commands
```bash
cd /workspace/studex-pipeline

# Verify all accounts are connected
node src/pipeline.js --test-accounts

# Show queue depth + next post
node src/pipeline.js --status

# Post next item from queue to all platforms
node src/pipeline.js --post

# Post to specific platforms only
node src/pipeline.js --post --plat facebook,linkedin

# Interactively add a post to the queue
node src/pipeline.js --add

# Add from JSON file
node src/pipeline.js --add --file ./content-queue/my-post.json
```

### Cron Setup (post every 6 hours)
```bash
0 0,6,12,18 * * * cd /workspace/studex-pipeline && node src/pipeline.js --post >> logs/cron.log 2>&1
```
