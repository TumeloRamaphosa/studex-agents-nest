## What It Does

A live order tracking dashboard for SA HORECA (Hotels, Restaurants, Catering) buyers — built tonight's research brief priority #1: HORECA buyers need **order transparency** to trust a supplier.

**Features:**
- **KPI bar** — Total orders, active orders, delivered count, total order value
- **Status filter chips** — Processing / Confirmed / Dispatched / In Transit / Delivered / Cancelled
- **Search** — Find by order number, customer name, business, or destination
- **Order cards** — Customer, business (hotel/restaurant), destination city, item summary, total
- **Order detail panel** — Click any order for full breakdown: items, tracking #, courier, delivery notes
- **5-step progress bar** — Visual pipeline: Placed → Confirmed → Dispatched → In Transit → Delivered
- **Shopify Connect modal** — Enter store URL + Storefront Access Token to pull live orders
- **Live mode** — Auto-refreshes every 60s when connected to Shopify
- **6 demo HORECA orders** — Saxon Boutique Hotel, Theouth Event Catering, Grange Butchery, Royal Palm Conference Centre, Indalo Game Lodge, Africa CEO Summit Catering

## Technical Notes

- **Mock data fallback** — Ships with 6 realistic SA HORECA orders. No Shopify key needed to demo.
- **Shopify wiring** — `fetchShopifyOrders(cfg)` is a stub. Wire to real Shopify GraphQL API:
  ```
  POST https://{shop}/api/2024-01/graphql.json
  X-Shopify-Storefront-Access-Token: {token}
  ```
  Query: `orders(first:50, sortKey:CREATED_AT, reverse:true)` → map to `Order` type.
- **Styling** — Dark luxury theme (Studex brand: deep browns, gold accents #c49a3c, dark bg #0d0a08)
- **No Tailwind config needed** — Tailwind v4 with `@tailwindcss/vite` plugin
