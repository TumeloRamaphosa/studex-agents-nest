## What It Does

### Dashboard Features
1. **Account Status Panel** — Shows all 6 connected Blotato accounts (Facebook, Instagram, YouTube, LinkedIn, Threads, TikTok) with live connection status
2. **Automation Overview** — Lists all active DM automations with keywords, message previews, and button configs
3. **Setup Guide** — Step-by-step instructions for connecting the missing Facebook Page and Instagram business account
4. **Automation Templates** — Shows all 5 Facebook automation templates ready for deployment
5. **Deploy Button** — One-click deployment of all 5 Facebook automations (activates once Page is connected)
6. **Instagram Status** — Shows existing 4 Instagram automations (working, active)

### API Server
**File:** `/workspace/blotato-command-center/api-server.js`

REST proxy that wraps `mcporter blotato` CLI commands as HTTP endpoints:
- `GET /api/accounts` — list connected accounts
- `GET /api/automations` — list all automations  
- `POST /api/automations/create` — create new automation
- `GET /api/health` — health check

Deployed on: Orgo VM `http://47.236.124.79:3000`
