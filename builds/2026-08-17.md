### 2. DeliveryKPIs — Live Shopify Orders ✅
**File:** `studex-war-room/src/components/DeliveryKPIs.tsx`
**Change:** Upgraded from static mock data (Jun 2026) to live Shopify Storefront API integration.

**How it works:**
1. Reads `VITE_SHOPIFY_SHOP_NAME` + `VITE_SHOPIFY_ACCESS_TOKEN` from `.env`
2. Calls `GET /admin/api/2024-01/orders.json?status=any&limit=50`
3. Maps Shopify financial + fulfillment status to War Room order statuses
4. Falls back to mock data (7 realistic SA orders) if API unavailable
5. Shows live banner: `🟢 LIVE` / `⚠️ MOCK DATA` / `❌ API ERROR`

**New KPI:** Shopify order count card (was showing "0 API blocked")

**Environment vars needed (add to `.env`):**
```
VITE_SHOPIFY_SHOP_NAME=your-store.myshopify.com
VITE_SHOPIFY_ACCESS_TOKEN=shpat_xxxxxxx
```
