# BUILD REPORT — 2026-09-01

## Build: Studex × Blotato Content Pipeline v3

**What was built:** A fully automated content pipeline that creates, schedules, and publishes posts to LinkedIn, Facebook, Threads, Instagram, TikTok, and YouTube via the Blotato API v2 — plus a React dashboard to monitor and trigger the pipeline.

---

## What's Delivered

### 1. Pipeline Script (`studex-content-pipeline/src/pipeline.mjs`)
**Status:** ✅ Built and tested (dry-run confirmed)

A complete Node.js script that:
- Rotates through a 14-day content calendar (biltong, wagyu, caviar, coffee, Studex brand stories)
- Checks for duplicate posts before publishing (won't double-post same platform same day)
- Staggers posts: 9am, 12pm, 3pm SAST per platform
- Supports `--dry-run`, `--platforms=`, `--no-stagger`, `--force` flags
- Uses Blotato CDN media URLs (no broken CDN dependency)
- Exposes `--status` mode for dashboard integration

**API endpoints used:**
- `GET /v2/users/me/accounts` — fetch account IDs
- `GET /v2/posts` — check for duplicates
- `POST /v2/posts` — create posts with `scheduledTime` for queuing

### 2. React Dashboard (`studex-content-pipeline/dashboard/`)
**Status:** ✅ Built (dist ready) — deployment needs Netlify auth

A polished React dashboard with:
- **Pipeline Control** — select platforms, dry-run toggle, one-click "Run Pipeline"
- **Connected Accounts** — shows all 6 Blotato-connected platforms
- **Recent Posts** — last 30 days with published/scheduled/failed status
- **Scheduled Posts** — upcoming queue with timestamps
- **Content Calendar** — 7-day rolling preview with today's content highlighted

**Stack:** Vite + React, no Tailwind, custom CSS (dark theme, Studex gold/orange palette)

**Backend API Server (`server.mjs`):**
- Node.js + Express server that proxies Blotato API calls (keeps API key server-side)
- Endpoints: `GET /api/accounts`, `GET /api/posts`, `GET /api/scheduled`, `POST /api/pipeline/run`, `GET /api/calendar`
- Serves the React static build on the same port (SPA fallback)
- Runs on port 3001

## How to Deploy

### Dashboard + Backend (one command)
```bash
cd /workspace/studex-content-pipeline/dashboard
npm install
node server.mjs
# → Dashboard at http://localhost:3001
# → API at http://localhost:3001/api/*
```

### Deploy Backend to Cloud (example: Railway, Render, VPS)
```bash
# Copy server.mjs + src/pipeline.mjs to your server
scp dashboard/server.mjs root@your-vm:/opt/studex-blotato/
scp -r src/pipeline.mjs root@your-vm:/opt/studex-blotato/src/
# Then: npm install express on VM, run server.mjs
```

### Deploy React to Netlify
```bash
netlify deploy --dir=dashboard/dist --prod
# (Requires: netlify login)
```
