## What Was Built

**`/workspace/studex-social-dm-pipeline/`** — A production-grade Instagram DM automation server.

### Architecture

```
Blotato IG DM webhook
    ↓
POST /webhooks/blotato/instagram
    ↓
intent-detector.js  →  classify: ☕ coffee | 🥩 biltong | ✨ caviar | 💬 general
    ↓
clickup-logger.js   →  create ClickUp task in appropriate product list
    ↓
blotato-reply.js    →  send auto-reply DM (confidence ≥ 70%)
    ↓
Human review flagged for low-confidence and general inquiries
```

### Files

| File | Purpose |
|------|---------|
| `server.js` | Express webhook receiver + health/stats endpoints |
| `routes/instagram-dm.js` | DM webhook handler: parse → detect → log → reply |
| `services/intent-detector.js` | Keyword-based intent classifier (4 categories, 5 intent types) |
| `services/clickup-logger.js` | ClickUp task creator per product list |
| `services/blotato-reply.js` | Sends DM replies via Blotato API |
| `services/pipeline-stats.js` | Morning stats aggregator |
| `services/logger.js` | JSONL audit log writer |
| `package.json` | Dependencies: express, axios, dotenv |
| `.env.example` | Environment variable template |
| `README.md` | Setup guide + architecture diagram |

### Intent Detection

Classifies incoming DMs into:
- **☕ Coffee** — Rwanda/Kenya/Ethiopian sourcing, hotel supply, sample requests, export inquiries
- **🥩 Biltong** — Gift boxes, subscription, braai/snack orders, wholesale
- **✨ Caviar** — Oscietra orders, corporate gifting, restaurant supply, luxury events
- **💬 General** — Hello, FAQ, catalog requests → flagged for human review

Intent types per message: `inquiry | purchase_intent | sample_request | b2b_inquiry | pricing_request`

### ClickUp Lead Logging

Creates tasks in the appropriate product list (coffee/biltong/caviar/general) with:
- Task name: `[IG DM] {Category} — {sender_handle}`
- Full message content + sender metadata
- Detected intent, confidence %, matched keywords
- Tags: category, instagram, social-dm, intent_type
- Priority: high (coffee/caviar), medium (biltong), low (general)

## Key Decisions Made

- **Why Express over n8n:** More portable, can run on Orgo VM without Docker. n8n requires more infra. This pipeline can be wired INTO n8n later as a node.
- **Why keyword-based intent:** Fast, deterministic, no API latency on every DM. Can upgrade to LLM classification later.
- **Why human review gate:** Confidence < 30% = always human. General category = always human. Avoids embarrassing auto-replies.
- **Why JSONL audit log:** Every DM interaction is logged to disk for compliance and debugging.
