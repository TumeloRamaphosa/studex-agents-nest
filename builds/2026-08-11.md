## What Was Built

**`/workspace/studex-voice-studio/`** — A React web app for generating AI voice messages and sending them via WhatsApp.

### Architecture

```
Text Input (React form)
    ↓
ElevenLabs API (TTS) — generates MP3 from text
    ↓
Preview + Download in-browser
    ↓
WhatsApp Business Cloud API — sends audio directly to customer phone
```

### Files

| File | Purpose |

| `src/App.jsx` | Main React component: text editor, voice picker, audio player, WhatsApp sender |

### Features

**Voice Scripts:**
- 4 preset templates: Order Confirmation, B2B Outreach, Discovery Box, WhatsApp Voice Note
- Live character count
- Free-form textarea for custom scripts

**Voice Selection:**
- Rhoko (Warm SA Male) — default, professional
- Naledi (Professional Female) — formal B2B
- Tumelo (Robusca Clone) — personal outreach

**Audio Generation:**
- ElevenLabs TTS API (streamed as audio/mpeg blob)
- Preview player embedded in browser
- Download as `.mp3` file for manual sharing

**WhatsApp Delivery:**
- Direct WhatsApp Business Cloud API (no Blotato dependency)
- Sends audio as WhatsApp audio message to any SA-format number (27...)
- Status confirmation with message ID on success

## Key Decisions Made

- **Why ElevenLabs over Qwen3-TTS:** ElevenLabs quality is significantly better for voice messaging. Qwen3-TTS is a fallback if ElevenLabs costs spike.
- **Why WhatsApp Cloud API directly (not Blotato):** Blotato has NO WhatsApp accounts connected — only FB/IG/YouTube/LinkedIn/TikTok/Threads. Direct WhatsApp Business API bypasses this gap.
- **Why React (not plain HTML):** Needs audio preview, dynamic voice switching, and WhatsApp sender form — easier with React state management.
- **Why dark luxury UI:** Matches Studex brand aesthetic (black/gold). Playfair Display serif for headings, Inter for body.
