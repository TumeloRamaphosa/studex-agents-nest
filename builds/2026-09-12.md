## What It Does

The Delivery Tracker tab gives Tumelo a real-time view of the entire order pipeline — from Instagram DM to delivered to door. It replaces the blind spot created by the missing Shopify API token.

**5 KPI Cards:**
| Metric | Value | Status |
|--------|-------|--------|
| Total Orders | 7 | All time |
| Active | 3 | In pipeline |
| Revenue | R8,170 | Confirmed |
| Avg Order | R1,167 | Per order |
| Cancels | 1 | This week |

**4 Delivery KPIs:**
- Delivered Today (green)
- Pending Delivery (blue)
- Courier Services — Sentech / Flexidrive (purple)
- Top Region — JHB (gold)

**Kanban Board — 5 columns:**
`PENDING → PROCESSING → SHIPPED → DELIVERED → CANCELLED`

**Order Cards show:**
- Order number + customer name + city
- Items ordered
- Total value (gold, prominent)
- Status badge with icon
- Source: Instagram / WhatsApp / Facebook / Website / Walk-in
- VIP or URGENT priority flags
- Payment status (Paid / Refunded)
- Courier notes (waybill numbers, delivery comments)
- Days ago

**Source Breakdown:** Horizontal bar chart by channel (Instagram dominant at 29%)
**Cities Covered:** All 6 delivery zones listed

**Alert Banner:** Flags the 1 cancelled order (ORD-002, R980 refund) with note to review checkout flow friction.
