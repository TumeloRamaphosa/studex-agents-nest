## What Was Built

### 1. n8n Order Pipeline Workflow v2
**File:** `/workspace/n8n-workflows/studex-order-pipeline-v2.json`

Full order-to-fulfillment pipeline. Triggered by Shopify webhook (POST `/webhook/studex-orders`).

**Pipeline steps:**
1. 🛒 **Shopify Webhook** — receives order payload from Shopify
2. ✅ **Create ClickUp Task** — creates task in War Room list with order details, customer info, items, priority 2, due in 24h
3. 💬 **Discord Notification** — posts order embed to #ops War Room channel
4. 📧 **AgentMail Customer ACK** — sends branded HTML confirmation email to customer
5. 📧 **Fulfillment Agent Alert** — sends task details to fulfillment agent inbox

**Environment variables required:**
- `CLICKUP_API_KEY` — ClickUp personal API token
- `CLICKUP_LIST_ID` — War Room list ID
- `CLICKUP_ASSIGNEE_ID` — assignee user ID
- `DISCORD_WEBHOOK_CHANNEL` — channel ID
- `DISCORD_WEBHOOK_ID` — webhook ID
- `AGENTMAIL_API_KEY` — AgentMail API key
- `AGENTMAIL_INBOX` — from address (e.g. `studex-2571@agentmail.to`)
- `FULFILLMENT_AGENT_EMAIL` — fulfillment agent's email
