## What Was Built

### Caviar Landing Page — AgentMail Integration

**File changed:** `/workspace/studex-caviar/src/App.tsx`

**What it does:**
The B2B inquiry form on the caviar landing page now POSTs to AgentMail when submitted — routing directly to `ceo@agent.studexmeat.com`. Before this build, the form set `submitted=true` locally with no actual delivery.

**Changes:**
- `handleSubmit` is now `async` — fires a `POST` to `https://api.agentmail.to/v0/messages/send`
- Auth header uses the AgentMail API key (`am_us_...`)
- Email subject: `Caviar B2B Inquiry — {Company} ({Topic})`
- Email body includes all form fields + timestamp + source page
- Added `submitting` state — button shows "SENDING..." and disables during flight
- Added `error` state — shows error message if API call fails
- Graceful fallback: if API fails, user sees error and can retry

**Research source:** Tonight's research brief confirmed CITES/DFFE compliance as a moat; wiring the inquiry form is the first revenue activation step for the caviar catalogue.
