### Secondary Build: WhatsApp Order Status Auto-Reply (n8n Workflow)

**Location:** `/workspace/n8n-workflows/whatsapp-shopify-autoreply.json`

**What it does:**
n8n workflow that:
1. Receives incoming WhatsApp messages via webhook (`POST /studex-order-status`)
2. Parses order numbers from messages like "order status #1234"
3. Looks up order in Shopify Admin API
4. Replies with formatted order status (fulfilled/pending, tracking number, total)

**Flow:**
```
WhatsApp message → Parse order # → Shopify API lookup → Status reply → Send WhatsApp
                                    ↓ (no order found)
                                  Help message reply
```

**Environment variables needed:**
- `SHOPIFY_ADMIN_API_TOKEN` — Shopify private app access token
- `WHATSAPP_TOKEN` — WhatsApp Cloud API page access token
