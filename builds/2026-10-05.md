Run with: `node blotato-post-scheduler.js [--dry-run] [--platform=tiktok|threads|facebook|all]`

## What It Does

Schedules a 5-day content sequence across TikTok, Threads, and Facebook via the Blotato API.
The script:
1. Reads connected accounts from Blotato API (`GET /v2/users/me/accounts`)
2. Creates and schedules posts for each platform (`POST /v2/posts`)
3. Reports success/failure per post with Blotato submission IDs
4. Saves results to `/workspace/builds/2026-10-05-blotato-scheduler.json`

**Verified API payload structure:**
```json
{
  "post": {
    "accountId": "48423",
    "content": { "text": "...", "mediaUrls": [], "platform": "tiktok" },
    "target": {
      "platform": "tiktok", "targetType": "tiktok",
      "privacyLevel": "PUBLIC_TO_EVERYONE",
      "disabledComments": false, "disabledDuet": false, "disabledStitch": false,
      "isBrandedContent": false, "isYourBrand": false, "isAiGenerated": false
    },
    "postTime": "2026-10-06T09:00:00.000Z"
  }
}
```
