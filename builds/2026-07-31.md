## What Was Built

### 1. n8n Shopify Fulfillment Workflow (`/workspace/studex-workflows/shopify-fulfillment-n8n.json`)

A production-ready n8n workflow JSON that orchestrates the entire Studex order fulfillment pipeline. Import directly into n8n.

**Workflow nodes (10 total):**

| # | Node | Type | Purpose |
|---|------|------|---------|
| 1 | 🛒 Shopify Order Created | trigger | Fires on order.created webhook |
| 2 | 📋 Parse Order Details | process | Extracts customer, items, total from Shopify JSON |
| 3 | 📦 Check Inventory | process | Queries Supabase for real-time stock |
| 4 | 🔀 Stock Available? | decision | Branches to fulfillment or OOS alert |
| 5 | 🎛️ Charlie Fulfillment | process | GPT-4o agent decides fulfillment path |
| 6 | 💬 WhatsApp Confirmation | notify | AgentMail WhatsApp template to customer |
| 7 | 📸 Blotato Social Post | notify | Auto-posts to FB + IG on every order |
| 8 | ⚠️ OOS Alert → Robusca | process | Assembles out-of-stock alert message |
| 9 | 📢 Discord Alert | notify | Posts OOS to #fulfillment channel |
| 10 | 📍 Update War Room | storage | POSTs order to War Room delivery tracker |

**Env vars required:**
- `SHOPIFY_ACCESS_TOKEN` — Shopify admin API token
- `SUPABASE_URL` + `SUPABASE_SERVICE_KEY` — Supabase project
- `OPENAI_API_KEY` — For Charlie GPT-4o agent
- `AGENTMAIL_API_KEY` + `AGENTMAIL_WHATSAPP_URL` — WhatsApp confirmations
- `BLOTATO_API_KEY` + `BLOTATO_FB_PAGE_ID` — Social auto-posting
- `DISCORD_WEBHOOK_URL` — #fulfillment channel webhook
- `WARROOM_WEBHOOK_URL` — War Room order tracker webhook

**Connections:**
- Shopify → Parse → Inventory → Stock Check
  - IN STOCK → Charlie → WhatsApp + Blotato → War Room
  - OOS → OOS Alert → Discord → Robusca
