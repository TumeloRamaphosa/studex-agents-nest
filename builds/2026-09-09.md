## How to Run

```bash
cd /workspace/studex-war-room

# See today's outreach plan
npm run outreach today

# Generate a WhatsApp message
npm run outreach message foodbarn first

# Mark as sent (logs the activity)
npm run outreach send foodbarn first

# Track status
npm run outreach status foodbarn
npm run outreach report
```
