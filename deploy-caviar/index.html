📋 Import Note for South African Buyers

Caviar is imported into South Africa under a permit stack. That stack is not assembled yet — so we publish it, name each issuer, and quote once it is confirmed.

✓ Permit stack named and tracked: DFFE → ITAC → DAFF → SARS → NRCS → CITES. Current status shared on request.
✓ Cold-chain temperature monitoring in transit
✓ Customs clearance handled — import duty and VAT quoted in the landed cost
✓ Refrigerated last-mile delivery to your door
✓ Certificate of origin from the supplier of each consignment
✓ CITES documentation where applicable
✓ DAFF veterinary import permit obtained before dispatch

Lead time: 7–14 days' commercial handling from order confirmation, counted from the date the DAFF veterinary import permit is issued. For a first shipment the permit must be applied for at least 4 weeks ahead and takes 5–10 working days to issue once approved — allow roughly two months end to end. Import duty and VAT are quoted in the landed cost; pricing is issued per enquiry.
