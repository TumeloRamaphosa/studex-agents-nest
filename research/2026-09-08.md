## 🎯 TOPIC 1: VOICEBOX — OPEN-SOURCE AI VOICE STUDIO

### What Is It?
**Voicebox** (jamiepine/voicebox) is a free, open-source, local-first AI voice studio. 52,653 GitHub stars — massive community adoption. Sits at `http://127.0.0.1:17493/mcp` as an MCP server, meaning AI agents can connect to it directly.

Replaces: ElevenLabs (output/TTS) + WisprFlow (input/dictation) in one app, running locally on your machine.

### Key Capabilities
| Feature | Detail |
|---------|--------|
| **Voice cloning** | Zero-shot from a few seconds of reference audio |
| **7 TTS engines** | Qwen3-TTS, Qwen CustomVoice, LuxTTS, Chatterbox (multilingual + turbo), HumeAI TADA, Kokoro |
| **23 languages** | English, Arabic, Japanese, Hindi, Swahili + 18 more |
| **Voice input** | Global dictation hotkey — speak into any text field, any app |
| **Voice agents** | Give AI agents a voice — MCP-aware |
| **Post-processing** | Pitch shift, reverb, delay, chorus, compression |
| **Stories editor** | Multi-track timeline for conversations/podcasts |
| **Privacy** | Everything runs locally — no cloud, no data leaving the machine |

### MCP Integration (Critical for Studex)
```
.mcp.json exposes:
"voicebox": {
  "type": "http",
  "url": "http://127.0.0.1:17493/mcp"
}
```
This means any MCP-aware agent (including OpenClaw) can connect to Voicebox and use it as a voice output layer. Robusca's AI agents could literally *speak* to customers.

### What This Means for Studex Customer Service
**Scenario A — Voice Agent on WhatsApp:**
"Hi, I'd like to order 2kg biltong" → AI agent receives text → Voicebox speaks the response in a warm South African voice → customer gets a voice note back on WhatsApp. Fully automated.

**Scenario B — Voice Clone of Robusca:**
Record 30 seconds of Robusca's voice → Voicebox clones it → all outbound voice messages sound like Robusca. Personal, trustworthy.

**Scenario C — Dictation + AI:**
Customer calls → Voicebox transcribes → OpenClaw agent processes → Voicebox reads back the response. A full voice QA pipeline, local and private.

### Limitations & Risks
- **Must run locally** — either on a local machine or on the Alibaba VM. Can't run on MaxClaw's cloud. Would need to be installed on the Orgo.ai VM or Alibaba VM.
- **No phone integration built-in** — it's a TTS/dictation studio, not a telephony system. WhatsApp voice notes need a separate integration (Blotato handles the posting, Voicebox handles the voice generation).
- **Setup complexity** — requires ffmpeg, Python, and audio setup. Not a 5-minute job.
- **Not a ready-made chatbot** — it's infrastructure, not a customer service solution out of the box.

### Opportunities for Studex
1. **WhatsApp voice notes from AI agents** — Blotato posts content, Voicebox generates the voice, OpenClaw orchestrates. A fully AI-powered social + voice sales funnel.
2. **Robusca voice clone** — customers hear a real human voice, not a robot. Trust multiplier.
3. **Call center alternative** — for order queries, product questions — voice + AI + WhatsApp, running 24/7.

### Verdict: 🔶 BUILDABLE, NOT READY TODAY
Voicebox is infrastructure, not a plug-and-play customer service tool. The workflow is:
1. Install Voicebox on Alibaba VM or Orgo VM (30-60 min)
2. Connect OpenClaw to Voicebox MCP endpoint
3. Build the WhatsApp voice pipeline (Blotato + Voicebox + OpenClaw)

**Lower-effort alternative first:** Use ElevenLabs (already configured in TOOLS.md) for voice output via the existing `sag` or `tts` tool. Voicebox is the *ambition* — get the business working first, then add voice.
