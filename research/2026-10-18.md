## TOPIC 1: Voicebox — Could It Power Studex Customer Service?

### What Voicebox Actually Is
*(Source: github.com/jamiepine/voicebox — 43,000+ GitHub stars)*

Voicebox is an **open-source AI voice studio** that runs locally on your machine. Two versions:

**Voicebox (desktop app)**
- Voice cloning: record 10–30 seconds of audio → clone any voice
- Text-to-speech with cloned voice
- Real-time narration, system-wide dictation
- Runs locally (no cloud, no API costs)

**Voicebox MCP Server**
- Every AI agent gets a voice. One tool call and any MCP-aware agent can speak to you
- Speaks task completions, questions, notifications in your cloned voice
- Built-in MCP server — connects to OpenClaw, Claude, Cursor, etc.

### What This Means for Studex

**Customer service use cases:**
- WhatsApp/phone: Clone Tumelo's voice → AI agent speaks to customers in his voice when they call or WhatsApp
- Order confirmations delivered as voice notes in Tumelo's voice
- After-hours support: AI agent answers FAQs and takes orders via voice
- For Naledi (CMO): voice version of content updates, voice DMs

1. Clone a voice: 10–30 seconds of Tumelo speaking

4. Set triggers: incoming WhatsApp → agent responds in cloned voice
