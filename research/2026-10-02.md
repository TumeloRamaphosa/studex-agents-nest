## TOPIC 2: Voicebox — AI Voice Studio

### What It Is
- GitHub: `jamiepine/voicebox` — 43k+ stars
- Free, open-source, local-first AI voice studio
- Voice cloning from a few seconds of audio
- Text-to-speech, multi-track audio
- Self-hostable; alternative to ElevenLabs and WisprFlow
- Runs on user's machine — no cloud dependency

### Could It Power Studex Customer Service?
**Short answer: Not yet, not for real-time.** Here's why:
- Voicebox is a *studio* tool (batching pre-recorded audio), not a real-time voice agent
- For live voice customer service, you'd need something like Twilio + an LLM (e.g., VOCAI, Retell AI, or ElevenLabs Conversational AI)
- Where Voicebox *could* help: Pre-recorded voice messages for WhatsApp audio replies, order confirmation voicemails, TTS for marketing content
- The ElevenLabs key is already in TOOLS.md — Studex already has better real-time voice capability via that integration

### Opportunity for Studex
- Use ElevenLabs (already configured) to generate audio messages for WhatsApp — "Your order has been dispatched" with Robusca's cloned voice
- Build Hour candidate: Voice-checkout flow (text order → WhatsApp audio confirmation)
