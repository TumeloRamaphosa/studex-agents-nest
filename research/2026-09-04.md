## Topic 1: Voicebox — Open-Source AI Voice Studio (Ver. 2 Update)

### What Changed Since Sep 3
Sep 3 brief identified Voicebox as the top priority for customer service automation. Tonight's deeper dive reveals a **critical blocker for the Alibaba Cloud VM**:

**Linux install = build from source only.** No pre-built binary for Linux. Prerequisites:
- Git + Rust + Bun + `just` (Rust task runner) + Tauri system deps
- Commands: `just setup` → `just build`
- Build output lands in `tauri/src-tauri/target/release/bundle/`
- This is non-trivial on a minimal Alibaba Cloud VM (2GB RAM, no GPU)

**Docker is NOT available for Linux** — the `docker compose up` path only works on macOS/Windows with the desktop app. On Linux, you're building from source.

### What This Means for Studex
- Voicebox on the **Alibaba Cloud VM is a 2-3 hour build project**, not a 10-minute Docker install
- On a 2GB RAM VM without GPU, voice generation will be slow/CPU-bound
- Better target: **Orgo VM** (8GB RAM) once it's restored, or Tumelo's MacBook Hub
- Voicebox MCP integration with studex-agent-core is the real prize — but only works when the agent runs on the same machine

### Opportunities
1. Voicebox MCP server = any AI agent can speak in a cloned voice with one tool call
2. 7 TTS engines including **Swahili** — relevant for East Africa expansion
3. Expressive tags `[laugh]`, `[sigh]`, `[cough]` via Chatterbox Turbo — more natural CS scripts
4. Free vs ElevenLabs R1,000+/month — massive cost saving for Naledi voice clone

## Topic 2: SA B2B Coffee — Hotels, Restaurants, Offices

### Key Findings

**Market size: USD 875M+ hotel/resort segment (2025), 9.7% CAGR.**
SA coffee market overall ~R12B/year. HORECA (Hotels/Restaurants/Cafes) accounts for ~40% of out-of-home consumption.

**Who the buyers are:**
| Segment | Key Players | Buyer Profile | Pain Point |
|---------|-------------|---------------|------------|
| **5-star hotels** | SUN International, Tsogo Sun, collection hotels | Procurement depts, slow, relationship-driven | Long supplier approval chains (3-6 months), need insurance + track record |
| **Fine dining** | La Colette, Greenhouse, Babel (Stellenbosch), The Test Kitchen | Head chefs, owners — story-driven, provenance matters | Can't get single-origin African coffees easily; most suppliers are commodity |
| **Cafes/boutique** | Truth Coffee (CPT), Deluxe (JHB), Stock + CAD (CPT) | Owners, baristas — quality obsessed | Inconsistent SA roasters, no full-African-story supplier |
| **Offices** | Riddled, Freshstop, selective SA office coffee suppliers | Facilities managers, procurement | Price-sensitive, commodity product, service consistency issues |

**Key insight — load shedding as differentiator:**
Load shedding is a **structural advantage** for SA coffee buyers: reliable supply + backup power story = premium value. No other African country has this angle. Studex can market "power-proof premium coffee" to SA hotel/facilities buyers.

**Competitor landscape:**
- Stock + CAD (CPT): SA roasters doing single-origin well, but no continental Africa story
- Deluxe Coffee (JHB): Premium, but focused on SA origins only
- **Gap**: No SA supplier with a pan-African coffee sourcing narrative (Ethiopia, Rwanda, Kenya, SA, Congo) + B2B gifting capability

**Pricing benchmarks (B2B green coffee):**
- Commodity grade: USD 3–5/kg FOB
- Single-origin specialty (Rwanda, Ethiopia): USD 8–18/kg FOB
- Studex target: USD 12–15/kg for Rwandan single-origin (competitively positioned below Kenya AA)

**Green coffee at record highs (2026):**
Arabica ~USD 7.50/lb (multi-year high). Robusta rising too. This is a headwind for B2B margins but signals a strong market. Lock in forward contracts with Rwandan suppliers now.

### Opportunities for Studex
1. **"African Coffee Story" B2B pitch deck** — target fine dining + boutique hotels first (faster sales cycle than 5-star)
2. **Load shedding resilience story** — position as the SA-grounded supplier that understands local infrastructure
3. **Bundle into existing biltong corporate gifting** — coffee sample + biltong box = stronger B2B entry
4. **Rwanda forward contract** — lock in 2027 supply now at current prices before further rises
