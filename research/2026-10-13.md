## Topic 1: Voicebox (jamiepine/voicebox)

### What It Is
Open-source, local-first AI voice studio. Free alternative to ElevenLabs + WisprFlow in one app. Runs entirely on your machine — voice cloning, TTS, dictation, multi-track audio editing. Supports 23 languages via Chatterbox Multilingual engine.

### What It Can Do
- Clone any voice from seconds of audio (no cloud)
- TTS in 23 languages, 50+ preset voices, voice creation from text description
- System-wide dictation (push-to-talk → any app)
- Emotion tags: `[laugh]`, `[sigh]`, `[whispering]` inline
- 8 audio effects (reverb, pitch, delay, compressor, chorus, etc.)
- **MCP support** — connects to Claude Code, Cursor, Cline via Model Context Protocol
- REST API + FastMCP server for custom integrations
- Stories editor for multi-track conversations/podcasts

### Technical Requirements
- macOS (Apple Silicon/Intel), Windows, Linux (Docker)
- Apple Silicon: MLX acceleration
- NVIDIA GPUs: CUDA; Windows: DirectML
- CPU capable but slower
- Python 3.12 + Rust + Bun to build from source

### Is It Ready for Studex Customer Service?
**No — not yet.** Voicebox is a desktop studio + developer tool. No telephony protocol support (SIP/VoIP), no live phone handling, no call center features. It's built for:
- Personal voice cloning (clone your own voice)
- Content creation (narration, podcasts)
- Agent voice output (MCP-connected coding agents)

**Verdict:** Skip for customer service right now. Revisit when live phone integration lands on the roadmap.

## Topic 2: Luxury Meat E-commerce — Competitive Landscape

### Global Biltong Market
- **$1.53B (2025) → $3.04B (2034) at 7.9% CAGR.** DTC and online are fastest-growing channels.
- **Top global players:** Jack Link's, Stryve Foods, Righteous Felon, Brooklyn Biltong, Biltong Baron
- **US market:** Largest regional at $513M (2025); North America is the prize market for premium SA biltong
- **Fastest growing region:** Asia Pacific at 10.1% CAGR — aligns with CIIE + China push

### Luxury Meat E-commerce Differentiators
What top competitors do differently:
1. **Subscription models** — Butcher Box ($89+/month), Good Chop ($120+) = predictable revenue + LTV
2. **Story + provenance** — Brooklyn Biltong leans hard on "authentic South African" origin story on Amazon storefront
3. **Flavor innovation** — peri-peri, garlic, exotic game (kudu, ostrich) beyond standard beef
4. **Format diversity** — meat sticks, biltong bites, powdered biltong as seasoning (not just slabs)
5. **Omnichannel** — supermarket presence (volume) + DTC (margin) + Amazon (discovery)
6. **Certification display** — Keto, Paleo, Whole30, grass-fed badges prominently shown

### South Africa E-commerce Context
- **$38.1B (2025) → $77.3B (2034) at 8.17% CAGR** — SA online is growing fast
- MEA luxury goods: $21.85B (2026) → $36.15B (2031) — luxury segment outpacing overall e-commerce
- Studex positioning: luxury African meat (biltong + wagyu biltong) into SA + export — niche within niche

### What Studex Should Know
- **Wagyu biltong = untested, premium whitespace.** No major competitor has a "wagyu biltong" product. This is a Studex-first positioning. Price it at 3–5x standard biltong.
- **Subscription box is the revenue lever.** Monthly delivery = predictable cash flow. Build this before scaling ad spend.
- **US Amazon is the distribution gap.** Brooklyn Biltong, Biltong Baron, Righteous Felon all sell there. Studex has zero US presence. CIIE may attract US distributor interest.
- **Certifications = trust signal.** Display keto, paleo, grass-fed, no additives on all product pages. This is table stakes for premium positioning.
