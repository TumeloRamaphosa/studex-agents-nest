- **n8n Agents launched August 5, 2026.** Define once, deploy anywhere — chat, API, or workflow trigger. Manager agent routes to sub-agents. Single-canvas multi-agent building (not scattered tabs anymore).
- **Architecture is now production-viable.** August 2025 multi-agent had reliability issues (Reddit consensus: no shared memory = not a "true" system). August 2026 update addresses orchestration. The "manager-subagent" pattern works for Studex's fleet of specialized agents.
- **n8n self-hosted on the Alibaba Cloud VM is the right move.** Full data control, no per-task pricing, connects Shopify/Discord/AgentMail in one workflow canvas.
- **n8n is ahead of Make.com on AI agent features** (Make is catching up but n8n wins on open-source flexibility).

### Key Findings — Voicebox

- **Voicebox (jamiepine/voicebox):** Free, open-source, MIT-licensed AI voice studio. 43,000+ GitHub stars. Local-first — no API costs, runs on Orgo VM or Alibaba Cloud.
- **What it can do:** Voice cloning (3 seconds audio), TTS across 8 engines + 23 languages, system-wide dictation, MCP server for AI agent integration, paralinguistic tags (laugh/sigh/whisper), built-in stories editor.
- **Technical requirements:** Runs on Mac (Apple Silicon MLX), Linux with NVIDIA GPU, or CPU-only (slower). ~1GB VRAM for lightweight model. **Deployable on Orgo VM (Ubuntu, 8GB RAM).**
- **For customer service:** Voicebox MCP server can connect to a Claude/agent harness for voice order status queries, FAQs, follow-ups. WhatsApp voice note → transcribe → agent respond → voice reply.
- **vs ElevenLabs Agents:** ElevenLabs has a full production voice agent platform (elevenlabs.io/agents) but costs per-minute. Voicebox is free but requires self-hosting and more dev work.

### Opportunities for Studex

- **n8n workflow:** Shopify order fulfilled → notify Discord #sales-alerts → Blotato sends WhatsApp to customer. Deployable TONIGHT on Alibaba Cloud VM.
- **Voicebox pilot:** Prototype a "Studex Order Bot" voice agent on the Orgo VM — WhatsApp voice note → voice reply with order status. Low cost, high wow factor.
- **n8n agent fleet orchestration:** Replace separate Zapier/Make workflows with n8n running on VM. More resilient, cheaper at scale, AI-native.
