## Topic 1: Voicebox — Open-Source AI Voice Studio

### Key Findings
- **Voicebox** (github.com/jamiepine/voicebox) is a local-first, free, open-source AI voice studio — ElevenLabs + WisprFlow combined, zero subscription.
- **Voice cloning:** Seconds of audio → cloned voice. Speaks in 23 languages via 7 TTS engines. All processing local — data never leaves the machine.
- **Built-in MCP server + REST API:** External AI agents (Claude Code, Cursor, etc.) can trigger voice generation. This is the key integration point for Studex.
- **Voice Personas:** Attach a branded persona to a voice profile + local LLM rewrites text "in character." Could power a Studex AI phone agent or WhatsApp voice bot.
- **Timeline editor:** Multi-track audio editing for podcasts, call scripts, training materials. Could replace needing ElevenLabs for long-form voice content.
- **Hardware:** Runs on Apple Silicon (MLX), NVIDIA CUDA, DirectML, AMD ROCm. Studex's Orgo VM (8GB RAM) could host it headless via REST API.
- **Already in stack:** `/workspace/studex-voice-backend/` and `/workspace/studex-voice/` exist — the team has already cloned Voicebox. Tonight's question: why isn't it deployed?

### Opportunities for Studex 🎙️

- **WhatsApp voice bot:** Voicebox + WhatsApp Business API = voice note responses to customers in SA languages (Zulu, Afrikaans, English).
- **Content pipeline:** Studex content team generates audio scripts via Voicebox, posts to Blotato → 9 platforms. No ElevenLabs subscription needed.
- **AgentMail voice responses:** Auto-reply to incoming emails with a voice note summary using Robusca's cloned voice.
