## 🎙️ TOPIC 2: VOICEBOX — INTEGRATION PATH

### What Voicebox Actually Is
`jamiepine/voicebox` — open-source, local-first AI voice studio (43k GitHub stars):
- **Voice cloning:** 10–30 sec audio → clone any voice
- **Text-to-speech:** 23 languages, runs entirely on local machine
- **No API calls:** Everything local = no per-minute costs, no data leaves Studex servers
- Free alternative to ElevenLabs (Studex already has ElevenLabs API key in .env)

### What It Can Do for Studex
- **Customer service phone agent:** Route WhatsApp/phone inquiries to voice agent that reads order status, answers FAQs
- **Branded voice identity:** Clone Naledi's voice for social media audio content — consistent brand sound
- **Order confirmation calls:** Automated TTS calls to confirm large orders (B2B bulk buyers)
- **Marketing:** Audio versions of Studex promotional content for WhatsApp distribution

### What It Cannot Do (Critical Limitations)
- **No real-time two-way conversation** — it's TTS/voice cloning, NOT a voice agent
- **No phone line integration** — needs to be wrapped with something like VAPI (already in Studex OS architecture) or Twilio
- **No LLM brain** — generates audio but doesn't understand/respond intelligently
- **Local install required** — must run on VM or desktop, not a simple API call

### Realistic Integration Path
```
Voicebox (voice cloning/TTS)
       +
VAPI (already in Studex OS) — handles real-time calls, STT, LLM routing
       =
Voice customer service agent
```
- Step 1: Install Voicebox on Orgo VM (`git clone + docker run`)
- Step 2: Clone Naledi's voice from existing WhatsApp audio clips
- Step 3: Connect to VAPI as TTS engine (replaces ElevenLabs for cost savings)
- Step 4: Wire up WhatsApp Business → VAPI → Voicebox for inbound customer calls
