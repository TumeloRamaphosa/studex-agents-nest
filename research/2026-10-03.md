## TOPIC 1: Voicebox (github.com/jamiepine/voicebox)

### What It Is
Open-source, local-first AI voice studio — free alternative to ElevenLabs + WisprFlow combined. Runs entirely on local hardware. No cloud subscription needed, data never leaves your machine.

### Key Capabilities
- **Voice cloning** from seconds of audio (zero-shot)
- **23 languages** via multiple TTS engines (Qwen3-TTS, LuxTTS, Chatterbox, Kokoro, HumeAI TADA)
- **REST API** exposed for custom integrations
- **MCP-native** — connects directly to AI coding agents (Claude Code, Cursor, Cline)
- **Global dictation** — speak into any app system-wide
- **Voice personalities** — attach a persona and a local LLM rewrites text to match tone before speaking
- **Stories editor** — multi-track timeline for podcasts/narratives
- **Audio effects** — reverb, pitch shift, chorus, delay built in

### Can It Power Studex Customer Service?
**Partially — needs custom build.** Voicebox has no native WhatsApp or phone integration out of the box. BUT its REST API makes it technically possible to:
- Build a voice agent that reads order updates, delivery ETAs, product info aloud
- Clone Tumelo's voice for a "CEO personally responds" feel on WhatsApp
- Use with n8n as the workflow layer between WhatsApp messages → Voicebox API → voice reply

**The practical path for Studex:**
WhatsApp → n8n workflow → Voicebox REST API (TTS) → voice response back to WhatsApp
Tools needed: Blotato (already have), WhatsApp Business API, n8n, Voicebox

### Verdict: ⭐ HIGH POTENTIAL for Build Hour
It's free, private, and the API makes it integrate-able. Cloning Tumelo's voice for customer service would be a genuine differentiator no competitor in SA is doing.
