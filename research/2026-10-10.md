## Topic 1: Agent Automation Tools — Blotato, Higgsfield, n8n/Make.com

### Key Findings

- **Blotato** — Social media API wrapper for AI agents. Flat pricing ($29/mo Starter), unlimited posts, 20+ accounts. Already has Studex API key confirmed working (TOOLS.md). KEY USE: AI agents posting directly to Facebook/Instagram without per-post fees. Gap: no WhatsApp Business integration yet — Blotato is social-only.

- **n8n vs Make.com** — Both are workflow automation platforms. n8n is open-source, runs locally/self-hosted (good for data privacy), has 1000+ integrations. Make.com is cloud-first, faster to set up, visual builder. For Studex: **n8n is the better long-term bet** — can run on the Alibaba cloud VM, full control, no per-task pricing. Make.com charges per operation and locks you into their cloud.

- **Higgsfield Supercomputer** — Agentic AI that runs full creative pipelines (websites, films, ad campaigns). MCP/CLI connection to Claude/ChatGPT/Cursor. New (Aug 2026): Blender add-on for 3D. RELEVANCE: Could automate Studex content creation pipeline — generate ad variants, product visuals, but compute-costly. Worth monitoring, not immediate priority.

- **n8n AI Agents** — Production-ready, customizable. Can connect to OpenClaw, ClickUp, AgentMail, Shopify. This is the **glue layer** between all Studex tools. Example workflow: New Shopify order → n8n → creates ClickUp task + sends WhatsApp confirmation + updates Google Sheet. Studex already has the Alibaba VM to host it.

- **Composio** (already connected) — Key differentiator. It connects to 100+ tools including Shopify, Gmail, Notion, WhatsApp, ClickUp. Already configured in TOOLS.md. **Strategic insight: Composio + n8n = full automation stack.** Composio handles the AI tool connections, n8n handles the workflow logic.

### Opportunities for Studex

- **Build the n8n layer now.** Run it on the Alibaba ECS VM. It becomes the workflow engine for all agent-to-agent and agent-to-external-system communication.
- **Expand Blotato usage.** Already confirmed working — connect it to the Naledi CMO agent for automated social posting. Schedule content, let agents approve/post via Blotato API.
- **Replace manual ops with n8n workflows.** Order confirmations, lead routing, CRM updates — all automatable.

## Topic 2: Voicebox — Open-Source AI Voice Stack

### Key Findings

- **Voicebox is a local-first, open-source voice I/O stack** (MIT license). Runs entirely on your machine — no cloud, no per-minute fees. Supports Apple Silicon/MLX, Windows/CUDA, Linux.
- **Key capabilities:**
  - Voice cloning from short audio samples
  - Text-to-speech generation (8 TTS engines including Qwen3-TTS, Kokoro, HumeAI TADA)
  - Global dictation (Whisper-based STT into any app via hotkey)
  - **Built-in MCP server** — AI agents (Claude Code, Cursor, custom) can trigger voice output via `voicebox_speak`
  - Expressive speech tags: `[laugh]`, `[sigh]`, `[angry]`
  - Unlimited generation length, 23 languages
- **The MCP server feature is the Studex opportunity.** An AI agent that can SPEAK to customers — real-time voice calls, not just text WhatsApp/Discord. Customer asks a question on WhatsApp voice note → agent responds with a voice note. This is next-level.
- **vs ElevenLabs:** ElevenLabs is cloud, paid per character. Voicebox is free, local, unlimited. Voicebox doesn't have ElevenLabs' brand voice quality yet — Kokoro is decent but not ElevenLabs-level. For Studex internal agent comms, Voicebox is fine. For customer-facing voice notes, ElevenLabs still wins on quality.
- **Status for Studex:** ElevenLabs API key is in TOOLS.md and set in .env. Voicebox would be a complementary layer — internal agents using Voicebox, customer-facing using ElevenLabs.

### Opportunities for Studex

- **Voicebox for internal agent training/oversight.** Clone Tumelo's voice, let agents listen to instructions spoken aloud. Useful for onboarding new agents.
- **WhatsApp voice note responses.** If AgentMail or WhatsApp integration matures, a voice output layer could auto-respond to voice messages with a spoken reply — zero typing required.
- **Pilot it on the Orgo VM.** Install Voicebox on the Ubuntu VM, test the MCP server with the Naledi or Charlie agent. Low cost, high signal.
- **Don't replace ElevenLabs for customer-facing yet.** Voice quality matters for brand. Use Voicebox for internal ops, ElevenLabs for anything client-visible.
