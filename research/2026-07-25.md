## 1. 🔊 VOICEBOX — Open-Source AI Voice Studio
**Source:** github.com/jamiepine/voicebox | 46.7k ⭐

### What it is
Local-first AI voice studio — a free, open-source alternative to ElevenLabs + WisprFlow combined. Runs entirely on your machine. Privacy-first: no audio ever leaves your device.

### Key Capabilities
- **Voice cloning** from seconds of audio (7 TTS engines: Qwen3-TTS, LuxTTS, Chatterbox, HumeAI TADA, Kokoro, etc.)
- **23 languages** including Swahili (relevant for AU expansion)
- **Dictation** — global hotkey, transcribes and pastes into any app
- **Agent voice output via MCP** — any MCP-aware agent (Claude Code, Cursor, Codex) speaks to you in a cloned voice
- **REST API + built-in MCP server** at `localhost:17493`
- **Post-processing** — pitch shift, reverb, chorus, compression
- **Stories editor** — multi-track timeline for podcast/conversation content
- **Tech stack:** Tauri (Rust), FastAPI (Python), Whisper STT, Qwen3 local LLM

### 🎯 What it means for Studex
- **Clone Tumelo's voice** → Auto-Meat and Dark Factory agents speak with the CEO's voice
- **Customer service voice bot** — build a voice AI agent that answers FAQs, takes orders, routes calls
- **Content pipeline** — dictate scripts, generate audio ads, voiceovers without ElevenLabs cost
- **Multi-agent identity** — Naledi (CMO) could have her own cloned voice, creating a recognizable brand sound

### Recommended Action
✅ **BUILD THIS HOUR:** Clone Tumelo's voice in Voicebox (5 min setup). Install Voicebox MCP on Orgo VM. Have Dark Factory agent speak order confirmations in the CEO's voice. Investigate `voicebox.speak` API for a WhatsApp/phone customer service bot.

## 2. ⚛️ HIGGSFIELD SUPERCOMPUTER — Agentic Content Factory
**Source:** higgsfield.ai/supercomputer-intro

### What it is
An AI agent that runs your entire creative pipeline from a single prompt. Think: "make a week of Instagram posts for Studex biltong" → it plans, picks the right models (Claude Opus 4.7, GPT-5.5 Pro, Gemini 3.1 Pro), generates, and delivers finished assets.

### Key Capabilities
- **Multi-agent pipeline:** brief → research → production → delivery
- **30+ connectors:** Slack, Drive, Notion, Gmail, Figma, and more
- **Skills marketplace:** reusable workflows like `/cinematic`, `/montage`, custom brand pipelines
- **Memory:** agent remembers context across sessions
- **Scheduled tasks:** daily ad variations, weekly competitor scans, monthly content calendars
- **Import from Claude/Claude Code/Codex:** bring existing skills and memory in
- **UGC Factory:** 100 ad variants per product in minutes
- **Cost:** credit-based, shows cost upfront before generating

## 3. 🔧 n8n — Open-Source Workflow Automation
**Source:** n8n.io | blog.n8n.io

### Why it matters for Studex
n8n is self-hosted (so Studex owns it), has AI nodes built-in, and connects to anything:
- **Shopify** (when token is fixed)
- **WhatsApp Business API**
- **Email (Gmail/SMTP)**
- **HTTP requests** (AgentMail, Blotato API, any custom endpoint)
- **Code execution** (JavaScript/Python inline)

### What to build in n8n
1. **Order confirmation flow:** Shopify order → WhatsApp message to customer → update ClickUp
2. **Content pipeline:** Naledi generates content → n8n posts to Facebook/Instagram via Meta Graph API → logs in Notion
3. **Lead routing:** Inquiry from website → classify (Biltong/Coffee/Caviar) → assign to relevant agent
4. **Shopify token monitor:** Check if Shopify API is accessible, alert if not

### n8n vs Make.com
n8n is open-source + self-hostable = Studex owns the infrastructure. Make.com is cloud-only. For a company with multiple agents and privacy-sensitive customer data, **n8n is the clear choice**.
