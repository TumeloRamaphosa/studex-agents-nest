## Topic 2: Voicebox v0.5.0 — AI Voice Studio with MCP Integration

**Key Findings:**

- 🎙️ **Voicebox is now a full AI voice I/O platform** — not just a voice cloner. v0.5.0 "Capture Release" (April 2026) added global dictation hotkey, MCP agent integration, and a built-in MCP server.
- 🤖 **MCP agent integration:** Any MCP-aware agent (Claude Code, Cursor, Cline) can call `voicebox.speak` to talk back to you in a voice you've cloned. One tool call = agent speaks to you audibly.
- 🌐 **23 languages, 7 TTS engines:** Qwen3-TTS, Qwen CustomVoice, LuxTTS, Chatterbox Multilingual, Chatterbox Turbo, HumeAI TADA, Kokoro. Swahili is included — relevant for East Africa potential markets.
- 🏠 **Runs locally:** Mac (MLX/Metal), Windows (CUDA), Linux (build from source), Docker. Your voice data never leaves your machine.
- 🔧 **Built with Tauri (Rust):** Fast, native performance — not Electron bloat.
- 📁 **Has a `.mcp.json`** in the repo — confirms first-class MCP support.

**What this means for Studex:**

| Use Case | Value |
|----------|-------|
| CEO agent (Robusca) reports verbally | Get a verbal briefing while you drive |
| Customer service voice bot | Voicebox handles inbound calls with a cloned Studex voice |
| Agent standup reports | Agents verbally brief you in the morning |
| WhatsApp voice responses | Not yet — Voicebox is desktop/local, not server-side |

**Limitations for Studex:**
- Voicebox is a desktop app — can't run on the Orgo VM headlessly for automated inbound voice calls
- For a production voice customer service bot, you'd need a voice-capable telephony integration (Twilio, etc.) separate from Voicebox
- BUT: For personal CEO productivity — getting verbal briefings from your agent — this is immediately usable

**Recommended actions:**
1. **This week (low effort, high novelty):** Install Voicebox on your Mac/PC → clone Tumelo's voice → get verbal briefings from Robusca agent
2. **Future build (Q4):** Explore Voicebox MCP server + Cursor AI to create a voice-enabled customer service prototype for Studex
